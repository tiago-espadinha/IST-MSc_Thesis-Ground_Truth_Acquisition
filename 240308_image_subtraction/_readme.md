# Image Subtraction

## Description

This folder contains MATLAB scripts developed for the Ground Truth acquisition for the VIENA project.
These scripts are designed to separate a moving object from the background in a video or a single image using image subtraction.

## Workflow

1.  Open MATLAB.
2.  Run `setup.m` to add the project paths to MATLAB and create the `assets` directory and copy the necessary assets into it from the project's `share-assets/` directory.
3.  Run the demo scripts in the `demos/` directory to see the functions in action:
    -   `demo_image_sub.m` to perform image subtraction on a single image.
    -   `demo_video_sub.m` to perform video background subtraction.

## Dependencies

-   MATLAB

## Contents

-   **`image_sub.m`**: Performs background subtraction on an image.
-   **`video_sub.m`**: Performs background subtraction on a video.
-   **`setup.m`**: Configures the project environment by copying assets and adding paths.

### `assets/`
-   Contains all the necessary files for the simulation to run, such as the videos and images.

### `demos/`
-   **`demo_image_sub.m`**: Demo for `image_sub.m`.
-   **`demo_video_sub.m`**: Demo for `video_sub.m`.

### `utils/`
-   **`subtract_background.m`**: Core image subtraction function.
-   **`create_bbox_mask_video.m`**: Creates a video mask from bounding box data.
-   **`save_results.m`**: Saves data, figures, or images to the `outputs` directory.

### `outputs/`
-   A directory where the output files are saved.

## Notes

-   The `tracking_bbox.mat` file, required for the second demo in `demo_video_sub.m`, is generated by the `video_track.py` script located in the `231102_yolo` directory. You need to run `video_track.py` to create this file before running the second demo.
