# VIENA Project - Ground Truth Acquisition and Simulation

## Description

This repository contains a collection of MATLAB and Python projects developed for the VIENA project, focusing on Ground Truth acquisition, vehicle simulation, and tracking for autonomous systems. The subprojects cover a range of techniques, including Model Predictive Control (MPC), Extended Kalman Filters (EKF), camera calibration, computer vision algorithms (like background subtraction and edge detection), and deep learning-based object tracking (YOLOv8).

Many of the simulations leverage the MATLAB Virtual Reality Toolbox to create and interact with 3D virtual environments, using assets defined in the `assets_3d` folder.

## Project Structure

The repository is organized into individual project folders, each named with a `YYMMDD_project_name` convention. Each folder is self-contained and includes its own README with specific instructions.

### Core Components

-   **`shared-assets/`**: A directory containing common assets used across multiple projects, such as videos, images, calibration data, and VRML models.
-   **`assets_3d/`**: Contains the source 3D models (`.blend`, `.dwg`) and the final VRML (`.wrl`) files used to build the virtual simulation environments.

### Sub-Projects Overview

#### Vehicle Control and Simulation
-   **`231228_MPC_sim`**: A MATLAB/Simulink project for simulating Model Predictive Control (MPC) to manage the speed and steering of an autonomous vehicle for path tracking.
-   **`240717_bus_ekf`**: A multi-vehicle, multi-camera EKF tracking simulation in MATLAB, designed to dynamically assign PTZ cameras to track multiple buses in a VRML world. Based on the thesis work of Tiago Castanheira.

#### Computer Vision and Tracking
-   **`231102_yolo`**: Python scripts using YOLOv8 for vehicle detection, pose estimation, and tracking in videos to generate ground truth bounding box data.
-   **`240308_image_subtraction`**: MATLAB scripts for separating a moving object from the background in videos or images.
-   **`240909_ekf_tracking`**: A MATLAB simulation that tracks a car in a VRML world using an Extended Kalman Filter (EKF).
-   **`241025_ekf_video_tracking`**: A hybrid MATLAB/Python project that tracks a vehicle in a real-world video. It uses YOLOv8 for detection and an EKF for tracking by matching edges from a VRML model.

#### Camera and Vehicle Calibration
-   **`240424_cam_calibration`**: MATLAB scripts for camera calibration and homography calculation using points from a VRML world.
-   **`240729_backgndsub_vrml_video`**: Estimates a vehicle's 6-DOF pose by aligning a 3D VRML model with a real-world image using background subtraction.
-   **`240916_edge_calib`**: Calibrates a vehicle and camera system by matching edges between a real image and a rendered VRML model to determine the vehicle's 6-DOF or 7-DOF pose.
-   **`241014_bev_tracking`**: Calculates a vehicle's position in a Bird's Eye View (BEV) perspective using homography.

#### Data and Analysis
-   **`241021_orbslam_plot`**: Contains trajectory data generated by ORB-SLAM3 for comparison and ground truth validation.

## General Workflow

Most MATLAB-based projects follow a similar setup pattern:
1.  Open the project folder in MATLAB.
2.  Run the `setup.m` script. This script typically adds the necessary subfolders to the MATLAB path and copies required files from the `shared-assets/` directory into a local `assets/` folder.
3.  Run the main script (e.g., `ekf_track.m`, `run_calibration.m`, `vrml_homography.m`) to execute the simulation or analysis.
4.  Check the `outputs/` directory for generated results, plots, and data.

For Python-based projects (like `231102_yolo` and `241025_ekf_video_tracking`):
1.  Navigate to the relevant directory (e.g., `241025_ekf_video_tracking/yolo/`).
2.  Install the required dependencies from `requirements.txt` or as listed in the subproject's README (`pip install -r requirements.txt`).
3.  Run the Python script (e.g., `python video_track.py`) to perform tasks like object detection.
